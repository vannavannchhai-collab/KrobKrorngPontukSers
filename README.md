# ប្រព័ន្ធគ្រប់គ្រងពិន្ទុសិស្ស — KrobKrorng Pontuk Sers

ប្រព័ន្ធពេញលេញសម្រាប់សាលារៀនកម្ពុជា ដើម្បីគ្រប់គ្រង **សិស្ស ថ្នាក់ មុខវិជ្ជា គ្រូបង្រៀន ពិន្ទុ វត្តមាន និងរបាយការណ៍សិក្សា** — ជាមួយការគណនាមធ្យមភាគ និទ្ទេស និងចំណាត់ថ្នាក់ស្វ័យប្រវត្តិ។

> ## ✨ គ្មានការចូលគណនី · គ្មាន database · គ្មាន server
> កម្មវិធីនេះដំណើរការ **ទាំងស្រុងក្នុងកម្មវិធីរុករក (browser)**។
> - **គ្មានទំព័រចូល (login)** — បើកមកគឺប្រើបានភ្លាម។
> - **គ្មាន database ឬ server** — ទិន្នន័យរក្សាទុកក្នុង `localStorage` របស់ឧបករណ៍។
> - **គ្មានទិន្នន័យគំរូ/គណនីសាកល្បង** — គ្មានសិស្ស ឬពិន្ទុក្លែងក្លាយទេ។
>
> **រក្សាសិទ្ធិគ្រប់យ៉ាងដោយ វណ្ណា វណ្ណឆៃ**

## 🚀 ដំណើរការលើកដំបូង

```bash
npm install
npm run dev        # http://localhost:5173
```

បង្កើតឯកសារសម្រាប់ដាក់លើម៉ាស៊ីនបម្រើ (static site)៖

```bash
npm run build      # → dist/
npm start          # build + preview នៅ http://localhost:4173
```

### ពាក្យបញ្ជា

| ពាក្យបញ្ជា | ការងារ |
|---|---|
| `npm run dev` | dev server ជាមួយ auto-reload |
| `npm run build` | build ឯកសារ static ទៅ `dist/` |
| `npm start` | build រួច preview នៅ port 4173 |
| `npm run preview` | preview ឯកសារ `dist/` ដែល build រួច |
| `npm run typecheck` | ពិនិត្យ TypeScript |

> មិនត្រូវការ `.env` ឬ environment variable ណាមួយទេ។

## ☁️ ដាក់ដំណើរការលើ Vercel

1. Push កូដទៅ GitHub។
2. Vercel → **Add New → Project** → ជ្រើស repo នេះ (Framework: **Vite** — រកឃើញស្វ័យប្រវត្តិ)។
3. ចុច **Deploy**។ រួចរាល់ — គ្មាន env var គ្មាន database ត្រូវភ្ជាប់។

`vercel.json` កំណត់រួចហើយ៖ build `npm run build` → `dist/` និង SPA fallback ទៅ `index.html`
(ដូច្នេះការបើក `/students` ដោយផ្ទាល់ក៏ដំណើរការ)។

អាចដាក់លើ Netlify, GitHub Pages ឬម៉ាស៊ីនបម្រើ static ណាមួយក៏បាន — គ្រាន់តែបម្រើថត `dist/`។

## 💾 ការរក្សាទុកទិន្នន័យ (សំខាន់)

ទិន្នន័យទាំងអស់ (សិស្ស ថ្នាក់ ពិន្ទុ វត្តមាន កំណត់ត្រា) រក្សាទុកក្នុង **`localStorage`** នៃកម្មវិធីរុករក
ក្រោមកូនសោ `kps.data.v1`។

| ចំណុចត្រូវដឹង | ការពន្យល់ |
|---|---|
| **នៅលើឧបករណ៍នីមួយៗដោយឡែក** | កុំព្យូទ័រ A និង B មិនឃើញទិន្នន័យគ្នាទេ (គ្មាន server ចែករំលែក)។ |
| **លុប cache / ប្ដូរ browser = បាត់** | សូម **នាំចេញឯកសារបម្រុងជាប្រចាំ**។ |
| **ឯកសារបម្រុង** | ការកំណត់ → ព័ត៌មានសាលា → «ទិន្នន័យក្នុងឧបករណ៍» → នាំចេញ / នាំចូល (`.json`)។ |
| **ផ្ទេរទៅឧបករណ៍ថ្មី** | នាំចេញឯកសារ `.json` ពីឧបករណ៍ចាស់ រួចនាំចូលនៅឧបករណ៍ថ្មី។ |
| **មិនត្រូវការអ៊ីនធឺណិត** | បន្ទាប់ពីបើកដំបូង កម្មវិធីដំណើរការ offline បាន (លើកលែងពុម្ពអក្សរ Google Fonts)។ |

## ✨ មុខងារសំខាន់ៗ

- **ផ្ទាំងគ្រប់គ្រង** — ចំនួនសិស្ស/ថ្នាក់/មុខវិជ្ជា មធ្យមភាគសាលា អត្រាជាប់ ក្រាហ្វនិទ្ទេស និងនិន្នាការតាមឆមាស
- **សិស្សានុសិស្ស** — បញ្ជី ស្វែងរក ត្រងតាមថ្នាក់/ភេទ/ស្ថានភាព បន្ថែម-កែប្រែ-លុប ផ្ទេរថ្នាក់ នាំចូល/នាំចេញ CSV
- **បញ្ចូលពិន្ទុ** — តារាងបញ្ចូលពិន្ទុតាមថ្នាក់/មុខវិជ្ជា/ឆមាស ជាមួយការព្រមានពិន្ទុលើសកំណត់
- **លទ្ធផលសិក្សា** — មធ្យមភាគមុខវិជ្ជា (ថ្លឹងតាមទម្ងន់) មធ្យមភាគរួម (ថ្លឹងតាមក្រេឌីត) និទ្ទេស ចំណាត់ថ្នាក់
- **សៀវភៅពិន្ទុ / សញ្ញាបត្រ** — ទម្រង់បោះពុម្ព A4 ជាមួយក្បាលប័ណ្ណសាលា
- **វត្តមាន** — កត់ត្រាប្រចាំថ្ងៃ តារាងប្រចាំខែ និងនាំចេញ CSV
- **ថ្នាក់រៀន / មុខវិជ្ជា / គ្រូបង្រៀន** — គ្រប់គ្រងពេញលេញ (គ្រូគ្រាន់តែជាបញ្ជីឈ្មោះ គ្មានគណនី)
- **ការកំណត់** — ព័ត៌មានសាលា ឆ្នាំសិក្សា/ឆមាស មាត្រដ្ឋាននិទ្ទេស ទម្ងន់ប្រភេទពិន្ទុ
- **កំណត់ត្រាប្រព័ន្ធ** — កំណត់ត្រាសកម្មភាព (audit) ក្នុងឧបករណ៍

### របៀបគណនា

- មធ្យមភាគមុខវិជ្ជា = Σ(ពិន្ទុ × ទម្ងន់) / Σ(ទម្ងន់) សម្រាប់តែការវាយតម្លៃដែលបានបញ្ចូល
- មធ្យមភាគរួម = Σ(មធ្យមមុខវិជ្ជា × ក្រេឌីត) / Σ(ក្រេឌីត)
- និទ្ទេស: A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60, E ≥ 50, F < 50 (កែបានក្នុងការកំណត់)
- ចំណាត់ថ្នាក់: តាមមធ្យមភាគ (ពិន្ទុស្មើ = ចំណាត់ថ្នាក់ស្មើ)
