### របៀបគណនា

```
មធ្យមភាគមុខវិជ្ជា = Σ(ពិន្ទុ × ទម្ងន់) ÷ Σ(ទម្ងន់ដែលបានបញ្ចូល)
មធ្យមភាគរួម      = Σ(មធ្យមភាគមុខវិជ្ជា × ក្រេឌីត) ÷ Σ(ក្រេឌីត)
និទ្ទេស          = A ≥ 90 · B ≥ 80 · C ≥ 70 · D ≥ 60 · E ≥ 50 · F < 50
```

ចំណាត់ថ្នាក់គណនាក្នុងថ្នាក់តាមមធ្យមភាគរួម (ពិន្ទុស្មើគ្នាទទួលបានចំណាត់ថ្នាក់ដូចគ្នា)។ ទម្ងន់ត្រូវបានធ្វើឱ្យស្មើស្វ័យប្រវត្តិ
ដូច្នេះការខកខានបញ្ចូលការវាយតម្លៃមួយ មិនធ្វើឱ្យសិស្សខាតបង់ពិន្ទុដោយអយុត្តិធម៌ទេ។

- **អ្នកគ្រប់គ្រង (admin)** — គ្រប់គ្រងទាំងអស់៖ សិស្ស ថ្នាក់ មុខវិជ្ជា គណនី ការកំណត់ និងពិន្ទុ។

## 🛠 បច្ចេកវិទ្យា

- **Frontend:** React 18 · TypeScript · Vite · Tailwind CSS · TanStack Query · Recharts · lucide-react
- **Backend:** Node.js 22 · Express · SQLite ដែលភ្ជាប់មកជាមួយ (`node:sqlite`) · Zod-ready validation
- **សុវត្ថិភាព:** JWT (12 ម៉ោង) · កូដពាក្យសម្ងាត់ `scrypt` · RBAC · SQL ប្រើ parameter ១០០% · audit trail
- **ភាសា:** UI ខ្មែរទាំងស្រុង (ពុម្ពអក្សរ Kantumruy Pro / Noto Sans Khmer ជាមួយ fallback ក្នុងម៉ាស៊ីន)

## 🚀 ដំណើរការ

```bash
npm install          # ដំឡើង dependencies
npm run build        # build frontend ទៅ dist/
npm start            # ដំណើរការម៉ាស៊ីនបម្រើ (http://localhost:4173)
```

ពេលដំណើរការលើកដំបូង ប្រព័ន្ធនឹងបង្កើត `data/school.db` និងបញ្ចូលទិន្នន័យគំរូដោយស្វ័យប្រវត្តិ។

| ពាក្យបញ្ជា | ការងារ |
|---|---|
| `npm run build` | build client (production) |
| `npm start` | ដំណើរការ server (បម្រើ API + dist) |
| `npm run dev` | ដំណើរការ server ជាមួយ auto-reload |
| `npm run typecheck` | ពិនិត្យ TypeScript |
| `npm run reset` | លុប DB ចាស់ និងបង្កើតទិន្នន័យគំរូឡើងវិញ |

### អថេរបរិស្ថាន (ស្រេចចិត្ត)

```
PORT=4173          # ច្រកម៉ាស៊ីនបម្រើ
DB_PATH=...        # ទីតាំងឯកសារ SQLite
JWT_SECRET=...     # កូនសោចុះហត្ថលេខា token (បើមិនកំណត់ ប្រព័ន្ធបង្កើតដោយស្វ័យប្រវត្តិ)
```
